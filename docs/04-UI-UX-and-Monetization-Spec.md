# 04. Спецификация UI/UX (CodeBurn Aesthetic), Попапа Перехвата и Нативной Монетизации

## 1. Визуальная философия и референс (`https://codeburn.app/`)

> **Главное требование к фронтенду для агента-разработчика: НИКАКОГО «ИИ-слопа» (No AI Slop UI)!**
> Запрещены кислотные фиолетово-розовые градиенты, огромные эмодзи на пол-экрана, раздутые карточки с гигантскими тенями и мультяшные иконки.
> В качестве эталона визуального стиля берется **[CodeBurn (codeburn.app)](https://codeburn.app/)** — нативная, утилитарная, плотная по информации (data-dense) инженерная утилита в стиле macOS Menu Bar Popover / Linear / Raycast.

### 1.1. Дизайн-система и токены (Design Tokens)

| Элемент | Значение (Tailwind / CSS) | Описание (Стиль CodeBurn) |
| :--- | :--- | :--- |

## 2. Архитектура окон (Menu Bar Popover + Interceptor Modal)

По аналогии с **CodeBurn**, приложение не загромождает рабочий стол огромным окном:

### 2.1. Строка меню (Menu Bar / System Tray Bar)
* В строке меню macOS рядом с иконкой щита выводится компактный текстовый статус прямо у часов (как CodeBurn выводит `$0.00`):
  * Например: `🛡️ NL · 100%` (когда всё чисто) или `🛡️ TR · WARN` (когда турецкий IP блокирует Gemini) или `🛡️ RU · HOLD` (когда запросы заблокированы).
* Клик по иконке открывает **Quick-Access Popover (`380x520 px`)**, привязанный к иконке трея (или компактное окно без лишних рамок).

#### Ключевые элементы в стиле CodeBurn:
1. **Кольцо безопасности (`Trust Score Ring` `0–100%`):** Тонкое SVG-кольцо слева от IP-адреса. Если `100%` — зеленое, если есть несовпадение таймзоны или публичный ASN — желтое (`65%`), если IP в спам-базе DNSBL или страна в бане — красное (`0%`).
2. **Вкладка `Deep Audit (9)` (Детальный чекер как на 2ip.io):**
   * Выводит 9 строк проверок в моноширинном табличном виде:
     * `Geo Matrix` $\rightarrow$ `NL (Allowed for all 3 providers)`
     * `Spam Databases (DNSBL)` $\rightarrow$ `0/4 Listed (Spamhaus, SORBS, Barracuda, DroneBL)`
     * `IP Pinning` $\rightarrow$ `Matched (185.212.xx.xx)`
     * `Impossible Travel` $\rightarrow$ `Stable (1 country in 24h)`
     * `ASN / Datacenter` $\rightarrow$ `AS20473 (Verified Personal VPS)`
     * `IPv6 Leak` $\rightarrow$ `No Leak (IPv4 Only)`
     * `DNS Resolver` $\rightarrow$ `1.1.1.1 (Cloudflare NL)`
     * `OS Timezone & Locale` $\rightarrow$ `Europe/Amsterdam (Matches IP)`
     * `Wi-Fi Geolocation (OS)` $\rightarrow$ `Disabled (Safe)`

### 2.3. Экстренный Попап Перехвата (`AlertPopup.tsx`)

Когда приложение (`Claude Desktop`, `Cursor`, браузер) стучится на сервер ИИ при плохих параметрах, соединение ставится на паузу (`Hold`), и по центру экрана поверх окон всплывает строгое, контрастное инженерное окно (`480x420 px`) с тонкой красной/янтарной верхней границей (`border-t-2 border-rose-500`):

```text
+-----------------------------------------------------------------------+
| ● INTERCEPTED REQUEST                              HOLDING PACKET...  |
|   Target: api.anthropic.com:443 (Claude Desktop)        TTL: 54s      |
+-----------------------------------------------------------------------+
| Запрос заморожен до отправки. Обнаружены факторы блокировки аккаунта: |
|                                                                       |
|  [CRITICAL] Geo / Travel Anomaly                                      |
|  country_code: TR (Turkey) -> Banned for Gemini / High Fraud Claude   |
|                                                                       |
|  [WARNING]  Spam & Shared VPN Database (DNSBL)                        |
|  Listed in: DroneBL / AS9009 (M247 Shared Pool - 400+ users on IP)    |
|                                                                       |
|  [WARNING]  Environment Mismatch                                      |
|  system_tz: Europe/Moscow != ip_tz: Europe/Istanbul                   |
+-----------------------------------------------------------------------+
| ВЫБЕРИТЕ ДЕЙСТВИЕ:                                                    |
|                                                                       |
|  +-----------------------------------------------------------------+  |
|  | ⚡ 1. Инструкция по решению (Личный чистый VPN за 15 мин)     -> |  | <-- Primary Action (Emerald/White contrast)
|  +-----------------------------------------------------------------+  |
|                                                                       |
|  +-----------------------------------+ +---------------------------+  |
|  | ⛔ 3. Блокировать до смены сети    | | 2. Принять риск (Сессия)  |  | <-- Secondary zinc-800 buttons
|  +-----------------------------------+ +---------------------------+  |
+-----------------------------------------------------------------------+
```

#### Логика работы 3 кнопок в попапе:
1. **Кнопка 1: «Инструкция по решению (Личный чистый VPN за 15 мин)»**
   * Мгновенно сбрасывает опасный запрос (`HTTP 403`), спасая аккаунт.
   * Открывает главное окно на вкладке `VPN Guide` с пошаговым руководством по развертыванию собственного VPS с чистым статическим IP (Нидерланды / Германия / США) и партнерскими ссылками.
2. **Кнопка 2: «Принять риск и продолжить»**
   * Разрешает запросы к этому провайдеру на текущую сессию и мгновенно отпускает замороженный пакет (`HTTP 200 Connection Established`).
3. **Кнопка 3: «Блокировать запросы до смены подключения»**
   * Включает автоматический `Kill-Switch` для этого провайдера до тех пор, пока сетевой монитор не увидит смену IP на безопасный.

## 3. Встроенный Ридер Гайдов и Нативная Монетизация (`GuideViewer.tsx`)

Во вкладке `VPN Guide` (куда ведет Кнопка №1 из попапа) интерфейс оформлен как интерактивный технический чек-лист (в духе вкладки `Optimize Findings` в CodeBurn):

1. **Блок выбора хостинга (Нативные карточки партнеров):**
   * Выглядят не как рекламный баннер, а как сравнительная таблица инфраструктурных провайдеров с бейджами локаций (`NL`, `DE`, `US`, `FI`), способами оплаты (`Карта РФ / СБП`) и кнопкой `Copy Promo / Open Provider`.
2. **Интерактивная проверка после настройки:**
   * Внизу гайда расположена кнопка **`[📌 Verify & Pin Current IP]`**, которая сразу запускает проверку по 9 пунктам (включая спам-базы DNSBL) и закрепляет купленный VPS как единственно разрешенный для работы с ИИ.
